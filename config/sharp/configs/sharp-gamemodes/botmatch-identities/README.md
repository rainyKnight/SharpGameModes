# BotMatch identity catalog

`bot_info.json` is imported unchanged from
`XBribo/CS2-Bot-Hider` v0.3.4 (`53961880f2ac9b2722296dcd47363bf32c460822`).
It contains the professional-player Steam account IDs, crosshair share codes,
and scoreboard flair definition indexes used by the pure ModSharp BotHider
runtime.
