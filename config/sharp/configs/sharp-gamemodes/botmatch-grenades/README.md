# BotMatch grenade lineups

These 48 JSON route files are derived unchanged from
[`ed0ard/CS2-Bot-Improver`](https://github.com/ed0ard/CS2-Bot-Improver),
NadeSystem 1.1.7, commit
`af1639598b1d7ba64d4850a36f4c819500f3b8ea`.

The upstream project is licensed under AGPL-3.0; its complete license text is
included as `UPSTREAM-LICENSE`.

`SharpGameModes.BotMatch` loads only files matching the current map and builds a
200-unit spatial index in memory. The files cover:

- `cs_italy`
- `cs_office`
- `de_ancient`
- `de_anubis`
- `de_cache`
- `de_dust2`
- `de_inferno`
- `de_mirage`
- `de_nuke`
- `de_overpass`
- `de_train`
- `de_vertigo`
