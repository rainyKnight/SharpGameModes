# BotMatch cosmetic data

`cosmetic_catalog.json` and `charm_placements.json` are the BotRandomizer
data files from `ed0ard/CS2-Bot-Improver`, pinned to commit
`af1639598b1d7ba64d4850a36f4c819500f3b8ea` (2026-07-27).

The SharpGameModes BotMatch runtime ports the matching stable per-bot selection,
weapon wear allocation, sticker-craft and weapon-aware charm placement
algorithms to pure ModSharp. The data and the port remain covered by the
upstream GNU AGPL license in `UPSTREAM-LICENSE`.
